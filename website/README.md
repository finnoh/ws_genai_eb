# Website

Participant companion for **AI Agents in Economics and Business Research**, built with [Docusaurus](https://docusaurus.io/). Workshop dates: **May 13–14, 2027**.

- **Day 1 · May 13:** AI Agents in Research (Beginner), E07–E12.
- **Day 2 · May 14:** Building AI Agents (Advanced), E01–E06.

Existing `day1` and `day2` route/asset names are historical identifiers and remain stable; display order follows the dates above.

## Installation

```bash
npm install
```

## Local Development

```bash
npm run start
```

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.

## Build

```bash
npm run build
```

This command generates static content into the `build` directory and can be served using any static contents hosting service.

Preview the production build with `npm run serve`. The local site is served below `/ws_genai_eb/`, not the host root.

## Visual system

- `src/css/custom.css`: neutral surfaces, near-black text, a restrained cobalt accent, flat navigation, and editorial content styles.
- `src/pages/index.tsx` and `index.module.css`: typographic homepage, accessible agent-workflow diagram, and chronological curriculum.
- Geist and Geist Mono are self-hosted through Fontsource; no third-party font request is needed.
- Prefer whitespace and thin rules over nested cards. Preserve visible keyboard focus and reduced-motion support. Check homepage, schedule, exercises, and slide pages at desktop and 375px widths after styling changes.
- `static/img/favicon.svg` is the node-network mark. `static/img/ti-ai-agents-social-card.svg` is the editable share-card source; its matching PNG is a 1200 × 630 browser rasterization at device scale 1 with no margins, used by Open Graph metadata.

Slide previews use the `.htm` files generated by `../scripts/render_slides.sh --skip-context` (run from the repository root as `./scripts/render_slides.sh --skip-context`). Keep these URLs intact: the local Docusaurus server rewrites `.html` deck requests. The removed Course Kickoff companion page and Block Write-up section should not be restored.

## Deployment

Using SSH:

```bash
USE_SSH=true npm run deploy
```

Not using SSH:

```bash
GIT_USER=<Your GitHub username> npm run deploy
```

If you are using GitHub pages for hosting, this command is a convenient way to build the website and push to the `gh-pages` branch.

## Live exercise runtime environment variables

Set these before building or deploying the live exercise site. Docusaurus exposes them to the exercise UI through its runtime configuration.

```bash
GOOGLE_FORM_URL=https://docs.google.com/forms/d/e/<FORM_ID>/viewform?usp=pp_url
GOOGLE_FORM_EXERCISE_FIELD=<ENTRY_ID_FOR_EXERCISE>
GOOGLE_FORM_GROUP_FIELD=<ENTRY_ID_FOR_GROUP> # leave blank: the current exercise UI does not prefill a group
ACTIVE_EXERCISE_ID=E01 # exposed for exercise-aware pages; currently not consumed by the exercise UI
RESULTS_SHEET_URL=https://docs.google.com/spreadsheets/d/<SHEET_ID>/edit
```

`GOOGLE_FORM_URL` and `GOOGLE_FORM_EXERCISE_FIELD` are required to generate prefilled exercise links. `RESULTS_SHEET_URL` enables the Results sheet link. `GOOGLE_FORM_GROUP_FIELD` remains available for future group-prefill support but is not used by the current UI.
