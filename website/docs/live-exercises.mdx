# Live Exercises

Use this page to open the participant response form for each exercise. Add an exercise ID to the URL, such as `?exercise=E01`, to highlight and focus its card.

Each card also provides a shareable prefilled link, the corresponding slide deck, and—when configured—the results sheet for facilitators.
